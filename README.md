# 学习资料工作台 · Study Desk

> 一个本地优先（local-first）的个人学习资料工作台：集中存放、分类、检索学习文档，并内置一个**完全在浏览器里运行**的分析引擎，帮你提炼摘要、归纳主题、发现知识缺口、生成可执行的学习建议。

零依赖 · 零构建 · 无后端 · 不上传任何数据。

**线上地址**：https://whoaru-1.github.io/study-desk/
**本地地址**：http://127.0.0.1:4173 （`npm start`）

## 功能

### 总览
资料总数、主题标签、备份完整度、主题覆盖度四项指标；文件类型环图、主题分布条形图、最近更新、智能洞察摘要；侧边栏「资料健康度」（备份 / 覆盖 / 复习新鲜度）。

### 资料库
- 拖拽或选择文件导入，也可直接粘贴文本
- 支持 `md / txt / html / csv / json / code` 正文解析（Markdown 标记会自动清洗），`pdf / docx / pptx` 记录元信息占位，可后续补充正文
- 标签筛选、关键词搜索（带上下文片段与命中高亮）、按更新 / 重要度 / 标题排序
- 资料详情面板：摘要、要点、关键词、标签增删、回溯原文、备份状态

### 知识主题
按标签聚合出「核心主题」卡片（覆盖度环形进度 + 主题关键词 + 结构评级），以及长尾标签和全库关键词热度。

### 智能分析
| 页签 | 内容 |
| --- | --- |
| 智能总结 | 每篇资料的一句话概括、3 条核心要点、关键词、关联数，可一键回溯原文 |
| 知识缺口 | 未归类、标签过细、标签重叠、缺练习材料、超 30 天未复习、未备份、孤立概念 |
| 内容关联 | 力导向关系图，节点大小 = 重要度，连线 = 共享关键词；悬停高亮邻居，点击打开详情 |
| 建议方案 | 复习计划 / 整理方案 / 学习路径 / 补强建议，每条含**依据、适用场景、优先级、执行步骤**，可一键采纳 |

### 备份
备份进度环、逐条 / 全部备份、自动备份开关、备份状态分布、完整 JSON 存档导出。

### 交互与隐私
iOS 极简风格：毛玻璃侧栏、分段控件滑动胶囊、底部抽屉（移动端可下拉关闭）、按压回弹、卡片错峰入场。
`⌘K` / `/` 聚焦搜索，`Esc` 关闭面板。**隐私遮罩**会把标题、正文、标签一起模糊。
数据只写入浏览器 `localStorage`（key：`studydesk.v1`），无任何网络请求。

## 本地运行

需要 Node.js ≥ 16（仅用于起静态服务器，项目本身无依赖）。

```bash
cd 工作台制作
npm start
# → http://127.0.0.1:4173
```

或者不用 npm：

```bash
node server.js          # 默认 4173
PORT=8080 node server.js
```

macOS 也可以直接双击 `start.command`。

> 服务器只监听 `127.0.0.1`，不会暴露给同网段的其它设备。

也可以直接双击 `index.html` 用 `file://` 打开——功能完全一致，只是没有本地服务器。

## 部署到 GitHub Pages

推送到 `main` 后，仓库自带的 Actions 工作流（`.github/workflows/deploy.yml`）会自动构建并发布：

1. 打开仓库 **Settings → Pages**
2. **Build and deployment → Source** 选择 **GitHub Actions**
3. 推送到 `main`，等待 Actions 完成
4. 访问 `https://<用户名>.github.io/<仓库名>/`

首次发布后如果 404，等 1—2 分钟或重新运行一次 workflow。

## 分析引擎是怎么工作的

全部在本地、纯规则可解释，不调用任何模型接口：

1. **分词**：领域词表最长匹配 → 掩码已识别片段 → 对剩余文本做 2—6 字 n-gram
2. **过滤**：去掉格式类标签（`习题`、`笔记`…）和泛化词（`分析`、`影响`…），再用「更长词组频次覆盖」剔除碎片
3. **摘要**：句子打分 = TF-IDF 权重和 × 位置权重 × 长度惩罚，取最高分句作 TLDR，其余高分句作要点
4. **主题**：按标签聚合，覆盖度 = 资料数量 + 类型多样性 + 复习新鲜度加权
5. **缺口**：未归类 / 长尾 / 标签重叠（Jaccard ≥ 0.8）/ 缺练习 / 久未复习 / 未备份 / 孤立概念
6. **建议**：由缺口与主题状态组合生成，带依据、场景、优先级与步骤
7. **关联图**：共享关键词 + 同主题加权建边，黄金角初始布局 + 斥力/弹簧/向心迭代，标签贪心放置、冲突则隐藏、悬停显示

想接真实大模型：替换 `js/engine.js` 暴露的 `Engine.analyze(docs)` 即可，界面层无需改动。

## 隐私

- 所有资料、摘要、标签只存在浏览器本地
- 无第三方脚本、无字体外链、无埋点、无网络请求
- `robots.txt` 默认禁止搜索引擎抓取；若希望公开索引，删除该文件即可
- 清空数据入口在「备份」页底部，会同时清理 `localStorage`

> 注意：`localStorage` 与浏览器配置绑定。换设备 / 换浏览器 / 清理站点数据都会丢，重要资料请用「导出备份」保存 JSON。
